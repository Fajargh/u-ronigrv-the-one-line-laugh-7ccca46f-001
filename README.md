# The One-Line Laugh

One original funny line, at most 200 characters, for make.fun's "The One-Line Laugh" bounty. `main.py` writes the line to `/output/entry.txt` — a single sentence with a surprise twist at the end, grounded in an everyday truth: buying a standing desk to fix your posture, only to end up slouching vertically instead of horizontally.

## Run it

```bash
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it.
